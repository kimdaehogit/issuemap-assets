개인정보처리방침

시행일: 2026년 9월 18일

"이슈맵 1분 상식"(이하 "서비스")은 운영자가 자신의 유튜브 채널에 영상을 게시하기 위해 사용하는 내부 자동화 도구입니다. 이 문서는 해당 도구가 Google API를 통해 접근하는 정보와 그 처리 방식을 설명합니다.

1. 수집하는 정보

서비스는 운영자 본인의 Google 계정에 한해 YouTube Data API를 통해 다음 권한을 사용합니다: 영상 업로드(youtube.upload), 채널 정보 조회(youtube.readonly). 일반 시청자나 제3자의 개인정보는 수집하지 않습니다.

2. 정보의 이용

취득한 접근 권한은 운영자 채널에 영상을 업로드하고 채널 통계를 확인하는 목적으로만 사용되며, 다른 목적으로 이용하거나 제3자에게 제공하지 않습니다.

3. 보관 및 보안

인증 토큰은 운영자의 컴퓨터에만 저장되며 외부 서버로 전송되지 않습니다. 운영자는 언제든 Google 계정 설정(myaccount.google.com/permissions)에서 접근 권한을 철회할 수 있습니다.

4. Google API 서비스 사용자 데이터 정책

서비스의 Google API 사용은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
